# PoemBook

Сборник стихов Вальдемара Громова. Vue 3 + Vite + Bun.

## Разработка

```bash
bun install
bun run dev
```

## Сборка

```bash
bun run build
```

Сайт публикуется на GitHub Pages из ветки `gh-pages` (`base: /poembook/`).

## Контент

Стихи хранятся в `src/data/`:

- `standalone.ts` — отдельные стихотворения
- `zerkalo.ts` — цикл «Зеркало Утерянной Души»
- `catalog.ts` — коллекции и поиск
